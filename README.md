
# Personal Website

My personal website, built with Astro and hosted on
GitHub Pages.

**Live Website:** https://brandonkimm.github.io

## About

I'm an Applied Mathematics–Computer Science student
at Brown University interested in machine learning,
computer systems, and security.

This website is a place to share my projects,
research interests, technical writing, and notes
on papers and books.

## Tech Stack

- Astro
- TypeScript
- HTML & CSS
- GitHub Pages
- GitHub Actions

## Local Development

The Astro application is located in the `website/`
directory.

```bash
cd website
npm install
npm run dev
```

To build the website:

```bash
npm run build
```

## Deployment

The website is automatically built and deployed
through GitHub Actions whenever changes are
pushed to the `main` branch.
